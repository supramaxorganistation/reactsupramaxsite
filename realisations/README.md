Place images for the Realisations gallery here.

Naming convention:
- realisations-1.jpg
- realisations-2.jpg
- realisations-3.jpg
- ...

The gallery component expects JPEG images named `realisations-{n}.jpg` placed directly in this folder.
Recommended sizes: 1200px or wider for best quality.

If you prefer linking external images instead of copying files, create a `links.json` file in this folder with a JSON array of image URLs, for example:

[
	"https://scontent.ftun15-1.fna.fbcdn.net/v/t39.1997-6/..../photo1.jpg",
	"https://external.ftun15-1.fna.fbcdn.net/....gif"
]

The gallery will load these URLs directly without downloading them.
